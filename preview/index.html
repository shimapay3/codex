Tab Injector

Chrome extension Manifest V3 — lưu một bộ JS + CSS riêng cho từng tab id và tự tiêm lại sau mỗi lần tải trang.

Manifest V3

Cài đặt (load unpacked)

  1. Mở chrome://extensions trong Chrome.
  2. Bật Developer mode ở góc trên bên phải.
  3. Bấm Load unpacked và chọn thư mục gốc của repo (thư mục chứa manifest.json).
  4. Ghim extension lên thanh công cụ rồi mở popup.

Cách dùng

  • Thêm bản ghi: đặt tên, chọn tab đang mở, chọn file JS và file CSS.
  • Click vào một bản ghi: extension mở đúng tab đó và tiêm JS + CSS đã lưu.
  • Áp dụng tiêm vào tab đang chọn; Tiêm lại mở tab và tiêm lại từ đầu.
  • Mỗi lần tab tải lại, bộ file của bản ghi được tiêm lại tự động.

Tab id đổi khi khởi động lại Chrome — khi đó bản ghi hiện “tab đã đóng”, chỉ cần lưu lại cho tab mới.
